# Leo's Babbel

The site at https://lxo96.github.io/Leos_babbel/ — Leo's apps, contact details and their privacy policies.

Plain HTML and CSS, served by GitHub Pages from `main` (no build step).

- `index.html`: the home page
- `wigglecam/privacy/`: Wigglecam's privacy policy (the URL given to Google Play)
- `assets/`: styles, the LB logo (the favicon) and the signature, taken from the Babbel artwork
- `assets/clouds/`: the palette clouds from the artwork, kept as a colour reference (not shown on the pages)
