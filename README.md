# Leo's Babbel

The site at https://lxo96.github.io/Leos_babbel/ — Leo's apps (Wigglecam and Quadsim, plus links to [Fisheye Print Extractor](https://github.com/LxO96/Photo360) and [Crem One Programmer](https://github.com/LxO96/One-Programmer)), contact details and their privacy policies.

Plain HTML and CSS, served by GitHub Pages from `main` (no build step).

- `index.html`: the home page
- `wigglecam/privacy/`: Wigglecam's privacy policy (the URL given to Google Play)
- `quadsim/privacy/`: Quadsim's privacy policy (the URL given to Google Play)
- `404.html`: shown by GitHub Pages for any missing page (its links are absolute, since it can be served at any path)
- `assets/`: styles, the LB logo (the favicon) and the signature, taken from the Babbel artwork
- `assets/share.png`: the preview image shown when a link to the site is shared
- `assets/fonts/`: Playfair Display and Crimson Pro, served from the site (SIL Open Font License 1.1, licenses alongside)
- `assets/clouds/`: the palette clouds from the artwork, kept as a colour reference (not shown on the pages)
